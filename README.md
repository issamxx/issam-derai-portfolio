# Issam Derai — Multilingual Developer Portfolio

A clean, responsive, zero-dependency personal portfolio website built with semantic **HTML5**, modern **CSS3**, and vanilla **JavaScript**.

🌐 **Live Demo (GitHub Pages):** `https://issamxx.github.io/issam-derai-portfolio/`

## Features

- **Multilingual (FR / EN / AR):** Instant client-side language switching with automatic `RTL` layout support for Arabic.
- **Light & Dark Theme:** Smooth theme toggle persisted in `localStorage`.
- **Interactive Skill Filter:** Filter technical skills across Development, Networks & Cybersecurity, and Design & Video.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile screens.

## Structure

- `index.html` — Semantic layout covering Hero, About, Skills, Experience & Education, GitHub Projects, and Contact.
- `styles.css` — CSS custom properties for light/dark themes, responsive grid layout, and RTL-safe logical properties.
- `script.js` — Full FR/EN/AR translation dictionary, theme switcher, and skill category filter.

## Local Preview

Open `index.html` directly in any modern browser, or serve locally:

```bash
python -m http.server 8000
```
